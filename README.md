# 🎯 AI 4-Level Quiz Maker (Shorts & TikTok Automation)

Autonomous AI video generation pipeline creating viral 4-level trivia challenges (Easy ➔ Medium ➔ Hard ➔ Impossible) optimized for YouTube Shorts, Instagram Reels, and TikTok.

## ✨ Features
- **4 Progressive Difficulty Levels**: Level 1 (Easy), Level 2 (Medium), Level 3 (Hard), Level 4 (Impossible).
- **Personal Local / Ngrok OpenAI-Compatible API**: Seamless generation strictly focused on user-specified topics with `gpt-4o`.
- **Word-by-Word Karaoke Highlighting**: Synchronized word timing via `faster-whisper`.
- **Smooth Gradient Countdown Timer**: Dynamic countdown bar transitioning smoothly from Emerald Green ➔ Golden Yellow ➔ Crimson Red over 2 seconds.
- **Dynamic Procedural Audio & BGM**:
  - Ticking sound during countdown.
  - Energetic reveal fanfare on answer reveal.
  - Upbeat suspense background music (120 BPM Lo-Fi pulse).
- **Seamless Outro Integration**: Auto-trims dead speech silence to exactly 0.3s before instantly stitching the permanent outro video.
- **Auto Telegram Publisher**: Automatically posts generated videos with high-retention English captions and hashtags.

## 🚀 Usage
```bash
python quiz_maker.py
```
Or run `تشغيل_صانع_الكويز.bat` from desktop.
